# 둘이서 💞

커플 둘이 같이 쓰는 앱. 두 사람 폰이 같은 데이터를 보고, 한쪽이 바꾸면 다른 쪽에도 바로 반영됩니다.

아래 탭 6개 + 홈 오른쪽 위 ⚙️ 설정:

- **🏠 홈** — D+며칠, 함께 키우는 나무(물 주기 · 배경 32가지), 오늘의 질문, 그때 오늘(1년 전·한 달 전), 다가오는 날, 도착한 편지
- **📅 추억** — [달력 | 앨범 | 편지] 공유 일기·반복 일정·생일 / 사진 모아보기 / 정한 날에 열리는 타임캡슐 편지
- **💬 대화** — [질문 | 밸런스] 질문 380개, 밸런스 150개. 둘 다 답해야 서로의 답이 열립니다
- **📍 지도** — 카카오맵에서 가고 싶은 곳을 저장하고, 그 안에 갈 카페·밥집을 모읍니다
- **⭐ 함께** — [영화 | 버킷리스트] 같이 할 것 목록. 한 뒤엔 둘 다 별점을 남깁니다
- **📊 통계** — 이번 달 우리 · 누가 더 많이 · 월별 기록 · 지금까지 우리
- **⚙️ 설정** — 사귄 날, 내 이름, 초대 코드, 알림, 백업, 비밀번호 바꾸기, 로그아웃

주소: https://minjejeong.github.io/make_application/

## 처음 설정하기 (한 번만, 10분)

두 폰을 연동하려면 데이터를 저장할 서버가 필요합니다. [Supabase](https://supabase.com) 무료 요금제를 씁니다.
설정 전에도 앱을 열면 **데모로 먼저 둘러보기**로 미리 써 볼 수 있습니다.

1. **프로젝트 만들기** — supabase.com 가입 → **New project**
   - Region: **Northeast Asia (Seoul)**
   - Database Password: 아무거나 길게 (앱에서는 안 쓰지만 잃어버리지 않게 보관)
2. **테이블 만들기** — 왼쪽 메뉴 **SQL Editor** → 새 쿼리 → [`supabase/setup.sql`](supabase/setup.sql) 내용을 전부 붙여넣고 **Run**
   - "destructive operation" 경고가 뜨면 **Run this query**를 누르면 됩니다
     (`drop policy if exists`가 들어 있어서 뜨는 경고고, 지우는 데이터는 없습니다)
   - 여러 번 실행해도 안전합니다
3. **메일 확인 끄기** — **Authentication → Sign In / Providers → Email**에서 **Confirm email**을 끄고 저장
   - 켜 두면 가입할 때마다 확인 메일 링크를 눌러야 하고, 무료 메일 발송은 시간당 몇 통으로 제한됩니다
   - 켜 둘 거라면 **Authentication → URL Configuration**의 **Site URL**을 위 주소로 바꿔 두세요
4. **주소와 키 복사** — **Project Settings**에서 두 값을 찾아 [`config.js`](config.js)에 붙여넣기
   - **Project URL** (`https://xxxx.supabase.co`) — Data API 메뉴, 또는 프로젝트 첫 화면 상단 **Connect**
   - **anon public 키** 또는 `sb_publishable_`로 시작하는 **Publishable key** — API Keys 메뉴

   ```js
   window.DURISEO_CONFIG = {
     supabaseUrl: "https://xxxx.supabase.co",
     supabaseAnonKey: "eyJhbGciOi...",
   };
   ```

   > ⚠️ `service_role` 키나 `sb_secret_` 키는 **절대** 넣지 마세요. 그 키는 모든 데이터를 마음대로
   > 읽고 지울 수 있습니다. anon/Publishable 키는 공개돼도 괜찮게 설계된 키라 깃허브에 올려도 됩니다
   > (누가 무엇을 볼 수 있는지는 setup.sql의 보안 규칙이 정합니다).
5. **올리기** — 아래 [배포](#배포)대로 push. 1~2분 뒤 사이트에 반영됩니다.

> **기능이 추가될 때마다 setup.sql을 한 번 더 실행**하세요 (영화·지도 `wishes`, 일정 `events`, 편지 `letters`, 알림 `push_subs` 등이 추가됩니다).
> 여러 번 실행해도 안전하고, 실행 전에는 새 기능 자리에 안내 문구만 뜨고 나머지는 그대로 쓸 수 있습니다.

## 비밀번호 찾기 설정 (한 번만)

로그인 화면의 **비밀번호를 잊었어요**는 메일로 재설정 링크를 보냅니다. 두 가지를 맞춰 두세요.

1. **링크가 앱으로 오게** — **Authentication → URL Configuration**
   - **Site URL**: `https://minjejeong.github.io/make_application/`
   - **Redirect URLs**에도 같은 주소 추가
2. **상대에게도 메일이 가게 (메일 보내기 설정)** — Supabase 기본 메일은 **프로젝트 팀원(가입한 본인) 주소로만** 보내집니다.
   상대 메일로도 보내려면 **Authentication → Emails → SMTP Settings**에서 내 메일 계정을 연결하세요 (무료).
   - Gmail 예시: Host `smtp.gmail.com` · Port `465` · Username 내 Gmail 주소 · Password **앱 비밀번호**
     (Google 계정 → 보안 → 2단계 인증 켜기 → '앱 비밀번호'에서 16자리 발급) · Sender email 내 Gmail 주소
   - 설정 전에는 상대가 재설정 메일을 요청하면 "이 메일로는 보낼 수 없어요"가 뜹니다

로그인한 상태에서는 **⚙️ 설정 → 비밀번호 바꾸기**로 메일 없이 바로 바꿀 수 있습니다.

## 알림 설정 (한 번만, 10분)

상대가 질문에 답하거나 기록·편지를 남기면, 그리고 생일·기념일·편지 열리는 날 아침 9시에 폰으로 알림이 옵니다.
서버 쪽에서 알림을 보내는 함수(Edge Function)를 한 번 만들어야 합니다.

1. **setup.sql 다시 실행** (알림 기기 테이블과 '기록이 생기면 알림 함수 부르기' 트리거가 들어 있습니다)
   - 실행 결과에 "pg_net을 켜지 못했어요"가 보이면 **Database → Extensions**에서 `pg_net`을 켜고 한 번 더 실행
2. **함수 만들기** — **Edge Functions → Deploy a new function → Via Editor**
   - 이름: `notify` (정확히 이 이름)
   - 내용: [`supabase/functions/notify/index.ts`](supabase/functions/notify/index.ts)를 통째로 붙여넣고 **Deploy**
3. **JWT 검사 끄기** — 함수 `notify` → **Details**(설정)에서 **Verify JWT with legacy secret / Enforce JWT verification**을 끄고 저장
   (트리거와 매일 아침 작업이 키 없이 부르기 때문. 함수는 받은 내용을 믿지 않고 DB에서 다시 읽어서 그 커플에게만 보냅니다)
4. **비밀키 넣기** — **Edge Functions → Secrets**(또는 Project Settings → Edge Functions)에서 추가
   - `VAPID_PRIVATE_KEY` = 알림용 비공개키 (저장소에 올리지 않고 따로 보관하는 값. 공개키는 config.js와 함수 코드에 있음)
   - 함수 로그에 "서버 키를 찾지 못했어요"가 보이면 `SERVICE_KEY` = Project Settings → API Keys의 `sb_secret_` 키도 추가
5. 각자 폰에서 **⚙️ 설정 → 🔔 이 폰에서 알림 받기**
   - **아이폰은 Safari에서 '홈 화면에 추가'한 앱으로 열어야** 켤 수 있습니다 (iOS 16.4 이상)
   - 폰마다 따로 켭니다. 로그아웃하면 그 폰 알림은 꺼집니다

같은 종류 알림은 연달아 오지 않게 묶습니다 (질문 답 30분, 밸런스 60분, 그 밖 10분에 한 번).
비공개키를 잃어버렸으면 키를 새로 만들어 config.js의 `vapidPublicKey`, 함수 코드의 `VAPID_PUBLIC`, Secret을 같이 바꾸고, 각자 알림을 다시 켜면 됩니다.

[`.github/workflows/daily.yml`](.github/workflows/daily.yml)이 매일 09:00(한국)에 돕니다.

## 지도 설정 (카카오맵, 한 번만)

지도 탭은 카카오맵을 씁니다. 무료이고, 키 하나만 받으면 됩니다.

1. [developers.kakao.com](https://developers.kakao.com) 로그인 → **내 애플리케이션** → **애플리케이션 추가하기** (앱 이름은 '둘이서' 등 아무거나)
2. 앱 설정에서 **카카오맵** 사용 설정을 **ON**으로 켜기 (꺼져 있으면 지도가 안 뜹니다)
3. **플랫폼 키** → **JavaScript 키**를 복사하고, 같은 화면의 **JavaScript SDK 도메인**에 `https://minjejeong.github.io` 등록
   - 등록 안 한 주소에서 열면 지도 자리에 "카카오맵을 불러오지 못했어요"가 뜹니다 (카카오가 401 domain mismatched로 막음)
4. [`config.js`](config.js)의 `kakaoMapKey`에 JavaScript 키를 넣고 push

> REST API 키·Admin 키는 넣지 마세요. JavaScript 키는 등록한 도메인에서만 동작하는 공개용 키라 깃허브에 올려도 됩니다.
> 카카오 콘솔 메뉴 이름은 가끔 바뀌니, 못 찾겠으면 '카카오맵 JavaScript 키 도메인 등록'으로 검색해 보세요.

## 둘이 연결하기

1. 둘 다 앱 주소로 들어가서 **처음이에요** 탭에서 각자 이메일로 가입
2. 한 사람이 **새로 시작하기** → 내 이름(상대에게 보일 이름)과 사귄 날 입력 → 6자리 **초대 코드**가 나옴
3. 다른 사람이 **초대 코드 있어요** → 코드 입력 → 연결 끝

그다음부터는 둘이 같은 캘린더·질문·밸런스·나무를 봅니다. 상대가 뭔가 하면 1~2초 안에 내 화면도 바뀌고,
앱을 다시 열 때도 최신 상태로 갱신됩니다.

## 폰에 앱으로 설치하기

- **아이폰(Safari)** — 주소 열기 → 아래 공유 버튼 → **홈 화면에 추가**
- **안드로이드(Chrome)** — 주소 열기 → 오른쪽 위 ⋮ → **앱 설치** (또는 홈 화면에 추가)

아이폰은 홈 화면 앱과 Safari가 로그인 정보를 따로 가져서, 설치한 앱에서 한 번 더 로그인해야 할 수 있습니다.
화면은 오프라인에서도 뜨지만, 기록을 불러오고 저장하려면 인터넷이 필요합니다.

예전 '둘이서 한잔'을 홈 화면에 설치해 둔 폰은 처음 열 때 옛 화면이 잠깐 뜨고, 몇 초 뒤 새 앱으로 저절로 다시 열립니다.
안 바뀌면 앱을 완전히 껐다(최근 앱 목록에서 위로 밀어서) 다시 켜세요. 그래도 안 되면 홈 화면 아이콘을 지우고 다시 설치하면 됩니다.

## 기능 자세히

### 오늘의 질문
하루에 하나씩, 커플마다 정해진 순서로 나옵니다 (둘의 폰에 같은 질문). 주제가 번갈아 나와서
가벼운 질문과 깊은 질문이 섞입니다. 지난 질문은 **대화 › 질문**의 주제별 목록에서 언제든 답할 수 있습니다.

| 주제 | 문항 |
|---|---:|
| ☕ 가벼운 이야기 | 60 |
| 🌱 서로 알아가기 | 70 |
| 💞 우리 이야기 | 60 |
| 💌 연애와 사랑 | 60 |
| 🌙 깊은 대화 | 70 |
| 🏡 함께할 미래 | 60 |

목록 표시: 💞 둘 다 답함 · 🔒 상대가 먼저 답함 (내가 답하면 열림) · ⏳ 상대 기다림 · ○ 아직

### 추억 › 달력
날짜를 눌러 사진 한 장과 메모를 남깁니다. 하루에 여러 개 남길 수 있고, 둘 다 쓸 수 있습니다.
사진은 올리기 전에 폰에서 긴 변 1600px로 줄여서 올라갑니다. 지우기는 **내가 쓴 기록만** 됩니다.
100일 단위 기념일과 주년은 달력에 표시됩니다.

- **일정·생일** — **📅 일정·생일 추가**(또는 날짜 창의 **이날에 일정·생일 추가**)에서 넣습니다.
  반복은 **반복 안 함 · 매주 · 매월 · 매년**. 🎂 생일·💝 기념일을 고르면 '매년'으로 맞춰지고, 생일은 태어난 날을 넣으면 'N번째 생일'이 붙습니다.
  매월 31일은 짧은 달엔 그달 마지막 날, 2월 29일은 평년엔 2월 28일에 뜹니다. 일정은 둘 다 고치고 지울 수 있습니다
- **같이 한 것** — 지도 **다녀왔어요**, 영화 **같이 봤어요**, 버킷리스트 **이뤘어요**를 고른 날짜에 📍·🎬·🏆가 자동으로 표시되고, 날짜 창에 목록이 뜹니다
- 편지가 열리는 날에는 💌가 표시됩니다
- 달력 아래 **N월에 있는 날**에 그달의 기념일·일정·같이 한 것이 모여 보이고, 홈의 **다가오는 날**에 가까운 3개가 뜹니다

### 추억 › 앨범
캘린더에 올린 사진을 달별로 모아 봅니다. 사진을 누르면 그날 기록이 열립니다. 60장씩 **더 보기**로 이어 봅니다.

### 추억 › 편지 (타임캡슐)
상대에게 편지를 쓰고 **열릴 날**(다음 기념일·한 달 뒤·1년 뒤·다가오는 생일·직접 고르기)을 정합니다.
그날(한국 날짜)이 되기 전까지 받는 사람은 **제목과 날짜만** 보고, 내용은 서버가 내주지 않습니다. 묻은 편지는 고칠 수 없고, 쓴 사람만 지울 수 있습니다.
편지가 열리면 홈에 **편지가 도착했어요** 카드가 7일 동안 뜹니다 (읽으면 사라짐).

### 홈 › 그때 오늘
1년 전·2년 전 … 오늘과 같은 날의 기록이나 같이 한 것을 보여줍니다. 없으면 한 달 전 오늘을 보여줍니다.

### 함께 › 영화 · 버킷리스트
보고 싶은 영화, 언젠가 같이 하고 싶은 것을 담아 둡니다. 한 뒤 **같이 봤어요 / 이뤘어요**를 누르면 아래 칸으로 옮겨지고,
각자 별점(1~5)과 한 줄 소감을 남기는데, 질문처럼 **둘 다 남겨야 서로의 별점이 보입니다**.
목록은 둘이 같이 써서, 누가 담았든 둘 다 고치고 지울 수 있습니다.

### 통계
- **함께한 지 N일**
- **N월의 우리** — 기록·사진·둘 다 답한 질문·밸런스 일치율·다녀온 곳·본 영화·이룬 버킷·모은 하트 (‹ › 로 달 바꾸기)
- **누가 더 많이** — 그달 기록·질문 답·밸런스·목록 담기를 둘이 나란히
- **월별 기록** — 최근 6달 막대. 누르면 그 달 통계로
- **지금까지 우리** — 전체 합계, 우리 평균 별점(상대 별점은 열린 것만), 모은 하트

### 설정 › 백업
**사진까지 전부 받기** / **글만 받기**로 zip 파일 하나를 받습니다. 안에 `data.json`(모든 기록), `우리의 기록.html`(열면 기록·답·사진이 보이는 페이지), `사진/` 폴더가 있습니다.
무료 서버라 가끔 받아서 컴퓨터나 클라우드에 보관해 두세요. 아직 안 열린 편지는 받는 사람의 백업에 내용이 들어가지 않습니다.

### 지도
장소 이름으로 검색해서(카카오 장소 검색) **가고 싶은 곳**으로 저장하면 지도에 핀이 꽂힙니다.
분류(맛집·카페·놀거리·여행·기타)와 메모를 붙일 수 있고, 다녀온 뒤 **다녀왔어요**를 누르면 '다녀온 곳'으로 옮겨지고
영화처럼 둘이 별점을 남깁니다. 분홍 핀 = 가고 싶은 곳, 초록 핀 = 다녀온 곳.

핀이나 목록에서 장소를 누르면 **그 장소 안으로** 들어갑니다 (예: 북촌 한옥마을).
- **이 근처에서 찾기** 또는 빠른 버튼(☕ 카페 · 🍽️ 맛집 · 🍰 디저트 · 🍺 술집 · 🎡 볼거리)으로 2km 안을 가까운 순으로 찾아
  그 장소에 추가합니다. 분류는 카카오 업종을 보고 먼저 골라 두고, 바꿀 수 있습니다
- 추가한 곳은 분류별로 모여 보이고 지도에 작은 핀으로 표시됩니다. 하나하나 메모·다녀왔어요·별점이 따로 있습니다
- 장소 자체의 메모·다녀왔어요·별점은 **메모·별점 ›** 에서. 장소를 지우면 안에 추가한 곳도 같이 지워집니다
- 지도 탭을 한 번 더 누르거나 ‹ 를 누르면 전체 지도로 돌아갑니다 (보던 위치 그대로)

### 하트와 함께 키우는 나무
둘이 활동하면 하트가 모이고, 모은 하트만큼 홈의 나무가 자랍니다. 하트로는 나무 배경을 엽니다. 나무와 하트는 둘이 같이 씁니다.

| 하는 일 | 하트 |
|---|---:|
| 처음 시작 | 30 |
| 나무에 물 주기 (하루 한 번, 한 사람당) | +2 |
| 그날 둘 다 물을 주면 | +2 더 |
| 질문에 답하기 (한 사람당) | +3 |
| 캘린더에 기록하기 | +2 |
| 밸런스 고르기 (한 사람당) | +1 |
| 다녀왔어요 · 같이 봤어요 · 이뤘어요 | +5 |

- **자라는 단계** (모은 하트): 🌰 씨앗 → 🌱 새싹 30 → 🪴 어린 나무 80 → 🌳 나무 160 → 🌳 큰 나무 300 → 🌸 꽃 피는 나무 500. 그 뒤로 200마다 주변에 나무가 한 그루씩 늘어 숲이 됩니다 (최대 12그루)
- 나무는 **모은 하트** 기준이라 배경에 하트를 써도 줄지 않습니다. 지갑(♥)은 모은 하트 − 배경에 쓴 하트
- 그림은 이 폰의 지금 시각에 따라 해·달·하늘색이 움직이고(5분마다 다시 그림), 실제 계절에 따라 벚꽃·열매·단풍·눈으로 바뀝니다
- **배경 32가지**: 계절(한강 벚꽃·계곡·바다·시애틀·산장), 기념일(할로윈·런던 크리스마스·야시장·놀이공원·달콤한 날), 여행(제주·궁궐·파리·산토리니), 판타지(해바라기·오로라·우주·바닷속), 명절(설날·추석·한글날·새해), 한국(부산·경주), 세계(뉴욕·도쿄·이집트·로마·시드니·베네치아·알프스). 호숫가는 무료, 나머지 ♥60~200
- **날짜 따라 저절로**(기본): 100일·주년 → 놀이공원, 설·추석 연휴 → 설날·한가위, 12/31·1/1 → 새해, 10/9 → 한글날, 2/14·3/14 → 달콤한 날, 12/1~25 → 런던 크리스마스, 10/15~31 → 할로윈, 금·토 저녁 6시부터 → 야시장, 그 밖엔 달마다 (3~5월 한강, 6월 계곡, 7~8월 바다, 9월~10/14 호숫가, 11월 시애틀, 12/26~2월 산장). 날짜 배경은 열지 않아도 그날엔 저절로 나옵니다. 생일(🎂 일정)엔 풍선이 떠요
- **배경 고정**: 홈의 나무 그림이나 🎨 배경을 눌러 상점을 열고, 연 배경을 고르면 그 배경으로 고정됩니다. ‘날짜 따라 저절로’를 누르면 다시 날짜 따라
- 설·추석 날짜는 `tree.js`의 `HOLIDAYS`에 2031년까지 들어 있습니다 (음력이라 해마다 미리 넣어 둠)
- 물 준 기록과 연 배경은 `room_items` 테이블에 저장합니다 (`water:날짜` · `bg:배경`). 새 테이블이 없어서 setup.sql을 다시 돌리지 않아도 됩니다
- 하트는 따로 저장하지 않고 활동 기록으로 매번 계산합니다. 기록을 지우면 그만큼 하트도 빠집니다. 예전 방 꾸미기에 쓴 하트는 돌려받습니다
### 연결 끊기
**⚙️ 설정** 맨 아래. 한 사람이 나가도 기록은 그대로 남고, 나간 사람은 같은 초대 코드로 다시 들어올 수 있습니다.

## 보안

- 모든 테이블에 행 단위 보안(RLS)이 켜져 있어서, **같은 커플 두 사람만** 그 커플의 데이터를 읽고 씁니다
- 사진 저장소는 비공개입니다. 앱은 6시간짜리 임시 주소로만 사진을 불러옵니다
- 커플은 최대 2명, 한 사람은 한 커플에만 들어갈 수 있습니다
- 초대 코드는 연결할 때만 쓰입니다. 두 사람이 한 번 연결되면 코드를 알아도 세 번째 사람은 들어올 수 없습니다
- 앱에서 고칠 수 있는 건 사귄 날·벽지·바닥·내 이름·내 기록뿐이고, 초대 코드나 소속 커플은 바꿀 수 없습니다
- 잠긴 편지의 내용은 서버가 받는 사람에게 내주지 않습니다 (열릴 날 전에는 쓴 사람만 읽을 수 있음)
- 알림 기기 정보는 각자 자기 것만 보고, 알림 함수만 서버 키로 읽습니다

## 문항·소품 고치기

전부 [`data.js`](data.js)에 있습니다.

> ⚠️ 질문과 밸런스는 **목록 안의 순서가 곧 id**입니다 (`light-1`, `light-2` … / `b-1`, `b-2` …).
> 저장된 답이 이 id를 가리키기 때문에, 한 번 쓰기 시작한 뒤에는
> - 새 문항은 각 목록의 **맨 뒤에만** 추가하고
> - 중간에 끼우거나, 지우거나, 순서를 바꾸지 마세요 (다른 질문에 답이 붙어 버립니다)
>
> 같은 뜻 안에서 문장을 다듬는 건 괜찮습니다.

- 질문: `categories[].qs` 배열에 문장 추가
- 밸런스: `balance` 배열에 `["A", "B", "카테고리"]` 추가 (카테고리는 `balanceCats` 중 하나)
- 소품: `objects`에 `{ key, e(이모지), name, price, cat, s(크기 배율) }` 추가. `key`는 겹치지 않게, 한번 정하면 바꾸지 않기

질문을 쓸 때는 **앞 질문 없이 혼자 읽어도 뜻이 통하게** 씁니다. 오늘의 질문은 순서를 섞어서 하나씩 나오기 때문에
"그때로 돌아가면…", "반대로…" 같은 질문은 무슨 뜻인지 알 수 없게 됩니다.

## 구조

빌드 과정 없는 정적 웹앱입니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 뼈대와 스타일 |
| `app.js` | 앱 전체 동작 (화면 · Supabase 연동 · 데모 모드) |
| `data.js` | 질문 · 밸런스 · 나무 단계 · 하트 규칙 |
| `tree.js` | 함께 키우는 나무 그림(SVG) · 날짜별 배경 · 배경 목록과 가격 |
| `config.js` | Supabase 주소와 공개 키, 카카오맵 JavaScript 키 |
| `supabase/setup.sql` | 테이블 · 보안 규칙 · 커플 연결 함수 · 사진 저장소 · 실시간 설정 (영화·장소는 `wishes`, 별점은 `wish_reviews`, 일정은 `events`) |
| `supabase/functions/notify/index.ts` | 알림 보내는 Edge Function (기록이 생길 때 · 매일 아침) |
| `.github/workflows/daily.yml` | 매일 09:00 서버 깨우기 + 오늘의 알림 |
| `vendor/supabase.min.js` | Supabase 클라이언트 (supabase-js 2.118.0) |
| `sw.js` | 오프라인 캐시 |
| `manifest.json`, `icon-*.png`, `apple-touch-icon.png` | 홈 화면 앱 설정과 아이콘 |
| `.nojekyll` | GitHub Pages의 Jekyll 처리를 건너뜀 |

외부에서 불러오는 건 Google Fonts(Jua, Noto Sans KR)와, 지도 탭을 열 때 받는 카카오맵 SDK(dapi.kakao.com)입니다.
