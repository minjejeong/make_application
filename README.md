# 둘이서 한잔 🍻

2인 전용 오프라인 술자리 게임. 폰 하나를 주고받으며 플레이합니다.

## 배포 (GitHub Pages)

저장소는 이미 연결돼 있습니다. 고친 뒤 push만 하면 됩니다.

```bash
cd /workspace/Unist_DOE/make_applicaiton
git add -A
git commit -m "수정 내용"
git push
```

**최초 1회만** GitHub 웹에서 Pages를 켜야 합니다.

1. https://github.com/minjejeong/make_application/settings/pages
2. Source: **Deploy from a branch**
3. Branch: **main** / **/ (root)** 선택 → **Save**

1~2분 뒤 아래 주소로 접속됩니다.

```
https://minjejeong.github.io/make_application/
```

## 폰에 앱으로 설치하기

이 게임은 PWA라서 홈 화면에 추가하면 앱처럼 동작합니다. 설치 후에는 **인터넷 없이도** 실행됩니다.

- **아이폰(Safari)** — 사이트 열기 → 하단 공유 버튼 → **홈 화면에 추가**
- **안드로이드(Chrome)** — 사이트 열기 → 우상단 ⋮ → **앱 설치** (또는 홈 화면에 추가)

아이콘이 생기고, 주소창 없이 전체화면으로 뜹니다.
처음 한 번만 인터넷에 연결된 상태로 열면, 그다음부터는 술집에 와이파이가 없어도 됩니다.

## 비밀번호

기본값 **1024**. 바꾸려면 `index.html`에서 이 두 줄을 함께 고치세요.

```js
const PIN_CODE   = "1024";
const UNLOCK_KEY = "unlocked_1024";   // 이것도 같이 바꿔야 함
```

`UNLOCK_KEY`는 "이 폰은 이미 잠금을 풀었다"는 표시를 저장하는 이름입니다.
PIN만 바꾸고 이 값을 그대로 두면, **이전에 한 번 열어본 폰에서는 잠금 화면이
아예 뜨지 않아** 비밀번호를 바꾼 의미가 없어집니다. 새 PIN에 맞춰 같이 바꾸세요.

> 참고: 이 PIN은 소스를 보면 노출됩니다. 모르는 사람이 우연히 들어오는 걸 막는 용도이지
> 암호학적 보안이 아닙니다. GitHub Pages는 주소를 아는 사람이면 누구나 접속할 수 있으니,
> 주소를 공유하지 않는 것이 실질적인 방어선입니다.
> 저장소를 Private으로 만들어도 **Pages로 게시된 사이트는 공개**입니다.

## 문항 추가하기

`index.html` 상단의 `CONTENT` 객체만 고치면 됩니다. `{A}`, `{B}`는 플레이어 이름으로 자동 치환됩니다.

`level`이 수위입니다. **고른 수위의 문항만 나옵니다** — 핵불닭을 고르면 핵불닭만 나오고
순한맛·매운맛은 섞이지 않습니다.

| level | 수위 | 기준 |
|---|---|---|
| 1 | 순한맛 | 연애·사적인 이야기까지 |
| 2 | 매운맛 | 두 사람 관계를 흔드는 딜레마 |
| 3 | 핵불닭 | 19금, 관계 파탄, 극단적 선택 |

각 수위에서 실제로 나오는 문항 수:

| 모드 | 순한맛 | 매운맛 | 핵불닭 | 보유 |
|---|---:|---:|---:|---:|
| 밸런스 게임 | 30 | 60 | 90 | 180 |
| 질문 카드 | 30 | 60 | 90 | 180 |
| 나에 대한 O/X | 30 | 60 | 90 | 180 |
| 미션 카드 | 30 | 30 | 30 | 90 |
| 둘 중 누구? | 60 | 60 | 60 | 180 |
| 3초 룰 / 초성 / 텔레파시 | 52 | 52 | 52 | 각 52 |
| 쫄? (핵불닭 전용) | — | — | 180 | 180 |

총 1,254개. 밸런스·질문·O/X는 수위가 올라갈수록 문항이 많아집니다
(30 → 60 → 90). 실제로 오래 노는 건 센 수위이므로 그쪽에 분량을 몰았습니다.

### 쫄? 모드

수위를 **핵불닭으로 맞췄을 때만** 로비에 나타납니다.

난이도는 **고를 수 없습니다.** 룰렛을 돌려서 나온 대로 강제로 주어집니다.

| 룰렛 결과 | 내용 | 실패 시 |
|---|---|---:|
| 🍺 가볍게 | 말·표정 수준 | 1잔 |
| 🔥 세게 | 스킨십 포함 | 2잔 |
| 💀 미친놈 | 최고 난이도 | 3잔 |

각 60개씩 총 180개. 해내면 벌주 없이 상대 차례로 넘어갑니다.

모드를 추가하려면 `MODES` 배열에 `only: 3`을 넣으면 그 수위에서만 나타납니다.
3초 룰·초성 릴레이·텔레파시는 수위 개념이 없어 어느 수위에서든 52개 전부 나옵니다.

```js
const CONTENT = {
  balance: [
    {a: "평생 여름만", b: "평생 겨울만", level: 1},
  ],
  truth: [
    {q: "{B}한테 고마웠는데 말 못 한 거 있어?", level: 2},
  ],
  // ...
};
```

고친 뒤, **`sw.js`의 캐시 버전도 함께 올리세요.** 안 올리면 이미 설치된 폰에서는
캐시된 옛 버전이 계속 뜹니다.

```js
const CACHE = "doori-v1";   // → "doori-v2" 로 변경
```

그다음:

```bash
git add index.html sw.js
git commit -m "문항 추가"
git push
```

1분쯤 뒤 사이트에 반영되고, 앱을 다시 열면 갱신됩니다.

## 구조

의존성 없는 단일 HTML 파일입니다. 빌드 과정이 없습니다.

- `index.html` — 게임 전체 (HTML + CSS + JS + 문항)
- `manifest.json` — 앱 이름·아이콘·전체화면 설정 (PWA)
- `sw.js` — 오프라인 캐시. **내용을 고치면 `CACHE` 버전을 올려야** 갱신이 반영됩니다
- `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` — 홈 화면 아이콘
- `.nojekyll` — GitHub Pages의 Jekyll 처리를 건너뜁니다
- `artifact.html` — claude.ai Artifact 게시용 사본 (`.gitignore`에 포함, 배포에는 불필요)

외부 의존성은 Google Fonts뿐이고, 폰트가 로드되지 않아도 시스템 한글 폰트로 폴백되어
게임 기능은 그대로 동작합니다.
