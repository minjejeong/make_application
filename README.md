## 폰에 앱으로 설치하기

이 게임은 PWA라서 홈 화면에 추가하면 앱처럼 동작합니다. 설치 후에는 **인터넷 없이도** 실행됩니다.

- **아이폰(Safari)** — 사이트 열기 → 하단 공유 버튼 → **홈 화면에 추가**
- **안드로이드(Chrome)** — 사이트 열기 → 우상단 ⋮ → **앱 설치** (또는 홈 화면에 추가)

아이콘이 생기고, 주소창 없이 전체화면으로 뜹니다.
처음 한 번만 인터넷에 연결된 상태로 열면, 그다음부터는 술집에 와이파이가 없어도 됩니다.

## 비밀번호

기본값 **1024**. 바꾸려면 `index.html`에서 이 두 줄을 함께 고치세요.

```js
const PIN_CODE   = "1024";
const UNLOCK_KEY = "unlocked_1024";   // 이것도 같이 바꿔야 함
```

`UNLOCK_KEY`는 "이 폰은 이미 잠금을 풀었다"는 표시를 저장하는 이름입니다.
PIN만 바꾸고 이 값을 그대로 두면, **이전에 한 번 열어본 폰에서는 잠금 화면이
아예 뜨지 않아** 비밀번호를 바꾼 의미가 없어집니다. 새 PIN에 맞춰 같이 바꾸세요.

> 참고: 이 PIN은 소스를 보면 노출됩니다. 모르는 사람이 우연히 들어오는 걸 막는 용도이지
> 암호학적 보안이 아닙니다. GitHub Pages는 주소를 아는 사람이면 누구나 접속할 수 있으니,
> 주소를 공유하지 않는 것이 실질적인 방어선입니다.

## 문항 추가하기

`index.html` 상단의 `CONTENT` 객체만 고치면 됩니다.

`level`이 수위입니다. **고른 수위의 문항만 나옵니다** — 핵불닭을 고르면 핵불닭만 나오고
순한맛·매운맛은 섞이지 않습니다.

| level | 수위 | 기준 |
|---|---|---|
| 1 | 순한맛 | 친구끼리도 꺼내기 민망한 사적인 얘기. 돈·흑역사·연애사 |
| 2 | 매운맛 | 숨기고 싶은 비밀과 속마음. 바람·전 애인·뒷담·돈·가족 |
| 3 | 핵불닭 | 남녀 둘이 썸~연인 직전. 서로를 이성으로 보는지 정면으로 묻는다 |
| 4 | 불지옥 | 19금. 잠자리 경험·취향·몸·판타지. 질문은 직설적으로, 묘사는 없이 |

### 성별 (핵불닭 이상)

로비 이름 칸 아래에서 각자 **남/여**를 고릅니다. 같은 쪽을 한 번 더 누르면 해제됩니다.
성별은 **핵불닭·불지옥에서 남녀일 때만** 반영되고, 순한맛·매운맛은 성별과 상관없습니다.
성별을 안 고르거나 동성끼리면 공통 문항만 나옵니다.

남녀일 때는 두 가지가 달라집니다.

1. 남자에게는 남자용, 여자에게는 여자용 문항이 섞여 나옵니다.
   밸런스는 보는 사람에 따라 문장이 바뀝니다
   (남자 화면 "여친이 남사친 새우 까주기", 여자 화면 "남친이 여사친 새우 까주기").
2. **여자 쪽이 한 단계 더 셉니다.** 여자가 '받는' 문항은 한 단계 위 수위에서 나옵니다.

| 고른 수위 | 남자가 받는 문항 | 여자가 받는 문항 |
|---|---|---|
| 핵불닭 | 핵불닭 (공통 + 남자용) | 불지옥 (공통 + 여자용) |
| 불지옥 | 불지옥 (공통 + 남자용) | 불지옥+ (여자 전용) |
| 쫄? | 걸린 칸 (공통 + 남자용) | 한 칸 위 (공통 + 여자용, 끝장 칸이면 끝장+) |

'받는 사람' = 질문 카드의 대답자, O/X의 주인, 진실의 눈의 대답자, 미션 받는 사람, 쫄?의 도전자.
밸런스·둘 중 누구·폭탄 돌리기·12층은 둘이 같은 문항을 같이 보므로 이 규칙이 없습니다.
같은 이유로 핵불닭에는 여자용(`g:"f"`) 문항이 없습니다 — 여자는 핵불닭에서 불지옥 문항을 받습니다.

문항에 성별을 다는 법:

- `g:"m"` 받는 사람이 남자일 때만 / `g:"f"` 여자일 때만. 없으면 공통
- `{남자일 때|여자일 때}` 기준인 사람의 성별에 맞춰 바뀌는 스위치. 이게 들어간 문항은 남녀일 때만 나옵니다
- 공통 문항에는 여친·남친·오빠 같은 성별 단어를 쓰지 마세요. 성별 미정·동성끼리일 때도 나옵니다

### 쫄? 모드

수위를 **핵불닭 이상으로 맞췄을 때만** 로비에 나타납니다.
칸은 **고를 수 없습니다.** 룰렛을 돌려서 나온 대로 강제로 주어집니다.

| 룰렛 칸 | 확률 | 내용 | 실패 시 | 문항 수 |
|---|---:|---|---:|---:|
| 🍺 가볍게 | 10% | 손깍지·애교·폰 가볍게 공개 | 1잔 | 110 (남 30) |
| 🔥 세게 | 20% | 포옹·백허그·손등 입맞춤·폰 깊게 공개 | 2잔 | 130 (남 25·여 25) |
| 💀 미친놈 | 30% | 볼 뽀뽀·무릎 위·입술 직전까지 | 3잔 | 130 (남 25·여 25) |
| ☠️ 끝장 | 40% | 입술 뽀뽀·키스·목·귓불·19금 고백 | 4잔 | 130 (남 25·여 25) |
| 끝장+ | — | 여자가 끝장 칸에 걸렸을 때 (여자 전용, `dare:5`) | 4잔 | 80 |

- 확률은 `DARE_TIER`의 `p`로 조절합니다 (합 100)
- 남녀일 때 여자는 같은 칸에서도 한 칸 위 도전을 받습니다. 벌주는 걸린 칸 그대로입니다
- 해내면 벌주 없이 상대 차례로 넘어갑니다
- 상대 몸이 걸린 도전이 많아서, **상대가 싫다고 하면** "🙅 ○○가 싫대요" 버튼으로 벌주 없이 넘어갑니다

모드 노출은 `MODES` 배열의 두 필드로 조절합니다.

- `min: 3` — 그 수위**부터** 나타남 (쫄?·폭탄 돌리기·진실의 눈)
- `max: 2` — 그 수위**까지만** 나타남 (3초 룰·초성 릴레이·텔레파시·러시안 룰렛)

핵불닭부터는 대화에 집중하는 수위라 가벼운 4개 모드를 감추고, 대신 전용 모드 셋을 엽니다.

- **쫄?** — 룰렛이 칸을 정하는 도전 게임
- **폭탄 돌리기** — 랜덤 시간(20~60초) 뒤 터진다. 남은 시간은 숨긴다
- **진실의 눈** — 답하는 쪽이 진실/거짓을 정하고 상대가 표정을 읽어 판정

### 12층 밸런스

유튜브 **십이층** 채널 스타일의 현실 딜레마 60개. 연애·직장·우정·돈·술자리에서
정답이 없는 선택지라 토론이 길어집니다. 수위 구분 없이 **전 수위에서** 열리므로 성적인 내용은 없고,
갈리면 60초 토론 뒤 설득당한 쪽이 마십니다.

### 문항 쓰는 규칙

- **말투** — 실제 술자리에서 하는 반말. 소리 내서 읽어보고 어색하면 고칩니다.
  "관계", "진심", "감정" 같은 추상어보다 구체적인 상황(읽씹, 깻잎 논쟁, 막차, 프사…)
- **그 자리에서** — 앉은 자리에서 바로 할 수 있어야 합니다. 밖에 나가기·자리 이동·눕기·
  준비물(반지, 향수 등)·"나중에 ~하기" 금지. 폰·술잔·안주·입고 있는 옷은 OK
- **애매한 것 금지** — 읽자마자 뜻을 알고, 성공·실패를 바로 판정할 수 있어야 합니다 (몇 초, 몇 번, 무슨 말)
- **스킨십 상한** (쫄?·미션) — 입술·키스, 목·귀·쇄골 입맞춤, 무릎 위, 옷 위로 허벅지까지.
  옷 벗기·성행위 흉내 금지
- **기록 금지** — 스킨십을 찍는 사진·영상·녹음, 상대 사진을 남에게 보내거나 SNS·프사에 올리는 도전은 넣지 않습니다
- 미성년 시절로 이어지는 질문(첫 경험 나이 등)은 넣지 않습니다

## 치환자

| 치환자 | 의미 | 쓰는 곳 |
|---|---|---|
| `{상대}` | **기준인 사람의 상대** 이름 | 밸런스, O/X, 미션, 쫄? |
| `{남자일 때\|여자일 때}` | 기준인 사람의 성별에 맞는 쪽 | 핵불닭 이상 |
| `{A}` `{B}` `{나}` | 1번·2번 플레이어 / 기준인 사람 자신 | 지금 문항에서는 안 씀 |

기준인 사람: 밸런스·12층은 화면을 보고 고르는 사람 각자, 질문 카드·진실의 눈은 대답하는 사람,
O/X는 주인, 미션은 받는 사람, 쫄?은 도전하는 사람.
민수가 보면 `{상대}`가 "지연", 지연이 보면 "민수"로 바뀝니다.
질문 카드·진실의 눈은 묻는 사람이 소리 내어 읽으므로 `{상대}` 대신 '나'(묻는 사람)와 '너'로 씁니다.

`{상대}` 바로 뒤 조사는 받침에 맞춰 자동으로 바뀝니다. 아래 형태로만 쓰세요.

| 쓰는 법 | 민수 | 지연 |
|---|---|---|
| `{상대}가` | 민수가 | 지연이 |
| `{상대}는` / `{상대}를` | 민수는 / 민수를 | 지연은 / 지연을 |
| `{상대}와` / `{상대}랑` | 민수와 / 민수랑 | 지연과 / 지연이랑 |
| `{상대}야` / `{상대}로` | 민수야 / 민수로 | 지연아 / 지연으로 |

`{상대}이랑`, `{상대}으로`처럼 쓰면 안 됩니다. 받침과 상관없는 조사(의, 한테, 도, 만)는 그대로 붙이면 됩니다.

## 밸런스 게임 문항 규칙

둘이 **같은 화면을 보고 동시에 고르는** 게임이므로, 보는 사람에 따라 의미가 달라지는
문항을 넣으면 안 됩니다.

```
✗ {B}가 내 뒷담 까기  ↔  내가 {B} 뒷담 까기     (각자에게 정반대 의미)
✓ 뒷담을 까였는데 모르고 지내기  ↔  뒷담을 깠는데 들키기
```

`{B}`를 쓰더라도 **양쪽이 같은 방향**이면 괜찮습니다
(`{B}와 평생 DM만 ↔ {B}와 평생 통화만`).

## 잔 수 카운터

화면 아래에 둘이 각각 몇 잔 마셨는지 계속 표시됩니다. 더 많이 마신 쪽이 분홍으로 강조되고,
가운데 ↺ 버튼으로 0으로 되돌릴 수 있습니다. 브라우저에 저장되어 앱을 다시 열어도 유지됩니다.

벌주는 모두 `drink(who, n, msg)` 한 곳을 거쳐 집계됩니다. **새 벌칙을 만들 때는 반드시
이 함수를 쓰세요.** `el("div","drink", ...)`로 직접 만들면 화면에는 뜨지만 카운터에 안 잡힙니다.

```js
const CONTENT = {
  balance: [
    {a:"내 통장 잔고 {상대}한테 공개", b:"지난달 카드 내역 {상대}한테 공개", level:1},
    {a:"{여친|남친}이 {남사친|여사친} 새우 까주기", b:"…", level:3},   // 남녀 스위치
  ],
  truth: [
    {q:"여자 볼 때 제일 먼저 보는 데 어디야?", level:3, g:"m"},      // 남자가 받을 때만
  ],
  dare: [
    {text:"{상대} 양쪽 볼에 한 번씩 뽀뽀하고 '한 번 더 해줄까?' 묻기", dare:3},  // dare = 쫄? 칸
  ],
  // ...
};
```

고친 뒤, **`sw.js`의 캐시 버전도 함께 올리세요.** 안 올리면 이미 설치된 폰에서는
캐시된 옛 버전이 계속 뜹니다.

```js
const CACHE = "doori-v1";   // → "doori-v2" 로 변경
```

그다음:

```bash
git add index.html sw.js
git commit -m "문항 추가"
git push
```

1분쯤 뒤 사이트에 반영되고, 앱을 다시 열면 갱신됩니다.

**대화가 터지는** — 밸런스 게임 · 질문 카드 · 나에 대한 O/X · 둘 중 누구? · 12층 밸런스
**분위기 전환** — 3초 룰 · 초성 릴레이 · 텔레파시 (매운맛까지)
**길게 가는** — 미션 카드 · 러시안 룰렛 (매운맛까지) · 쫄? · 폭탄 돌리기 · 진실의 눈 (뒤 셋은 핵불닭 이상)

## 구조

의존성 없는 단일 HTML 파일입니다. 빌드 과정이 없습니다.

- `index.html` — 게임 전체 (HTML + CSS + JS + 문항)
- `manifest.json` — 앱 이름·아이콘·전체화면 설정 (PWA)
- `sw.js` — 오프라인 캐시. **내용을 고치면 `CACHE` 버전을 올려야** 갱신이 반영됩니다
- `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` — 홈 화면 아이콘
- `.nojekyll` — GitHub Pages의 Jekyll 처리를 건너뜁니다
- `artifact.html` — claude.ai Artifact 게시용 사본 (`.gitignore`에 포함, 배포에는 불필요)

외부 의존성은 Google Fonts뿐이고, 폰트가 로드되지 않아도 시스템 한글 폰트로 폴백되어
게임 기능은 그대로 동작합니다.

## 나중에 앱으로 옮길 때

게임 로직이 순수 JS이고 `CONTENT` 데이터가 분리돼 있어서, React Native 등으로 옮길 때
문항 데이터는 그대로 복사하고 UI 렌더링 부분만 새로 쓰면 됩니다.
웹에서 충분히 플레이해보고 문항과 규칙을 다듬은 뒤에 옮기는 것을 권합니다.
